# 🎲 En Jeux — votre maître du jeu de poche

**https://pat37100.github.io/jeux/**

En famille ou entre amis, il anime, il compte, il arbitre — et retient qui gagne.

## Les 3 jeux
| | | |
|---|---|---|
| 🏆 **La Coupe** | *Il compte.* | Tous vos jeux à points (belote, tarot, Uno…) : manches, cumul, objectif de points, courbe de la course, cérémonie de couronnement |
| ⏱️ **Tic-Tac** | *Il chronomètre.* | Duel de temps façon plateau TV : arène côte à côte, 3-2-1-GO, son de tension, durée par joueur (handicap) |
| 🎙️ **Le Micro** | *Il anime.* | Quiz vocal animé par IA, adapté à chaque joueur, jamais deux fois la même question — 4 styles d'animateur |
